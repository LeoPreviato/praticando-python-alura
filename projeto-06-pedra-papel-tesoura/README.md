# Projeto 06 - Pedra, Papel e Tesoura

## 📖 Sobre
Este programa simula uma partida de Pedra, Papel e Tesoura entre o usuário e o computador. O usuário escolhe uma das opções disponíveis, o computador faz uma escolha aleatória e o programa verifica quem venceu a rodada.

## 🚀 Funcionalidades
- Permite que o usuário escolha entre Pedra, Papel ou Tesoura.
- Valida se a opção digitada é válida.
- Sorteia automaticamente a escolha do computador.
- Compara as escolhas do usuário e do computador.
- Informa se o resultado foi vitória, derrota ou empate.

## 🛠️ Tecnologias utilizadas
- Python 3
- Módulo `random`

## 💻 Exemplo de uso
**Entrada**
```text
Escolha Pedra, Papel ou Tesoura: Pedra
```

**Saída**
```text
Você escolheu: Pedra
O computador escolheu: Tesoura
Você Venceu!
```

*(a escolha do computador muda a cada execução, já que é sorteada aleatoriamente)*
